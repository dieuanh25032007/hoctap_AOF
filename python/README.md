# Python Programming

Thư mục lưu trữ mã nguồn các bài tập và chương trình Python phục vụ học tập.

## Công cụ & Môi trường
* **Môi trường lập trình:** IDLE Python 3.14.6
* **Hệ điều hành:** macOS (Visual Studio Code / Terminal / IDLE)

## Các nội dung & Chủ đề chính
* **`xuat_nhap_kho.py`**: Chương trình quản lý xuất nhập kho cơ bản.
* **Cấu trúc điều khiển:** Sử dụng vòng lặp (`for`, `while`) để duyệt và xử lý dữ liệu.
* **Cấu trúc dữ liệu:** Tra cứu và lưu trữ thông tin bằng Từ điển (`dictionary`).
* **Đọc, ghi và mở file (File I/O):** Thao tác với tập tin để lưu trữ dữ liệu lâu dài.
* **Xử lý ngoại lệ (Exception Handling):** Bắt lỗi (`try`, `except`) giúp chương trình hoạt động ổn định, tránh crash khi nhập sai dữ liệu.
